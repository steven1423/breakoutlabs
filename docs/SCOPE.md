# Scope

What is Live, what is Seeded, and what was cut. Updated at the end of every milestone.

Live means a real external API or real database logic in the production build. Seeded means synthetic data. If a milestone cannot meet its definition of done, this file says so and the page shows the same message.

## Data

All customer, kit, panel, ticket and attribution rows are synthetic, generated by `lib/synthetic` from a fixed seed. Creators are 30 seeded Instagram and TikTok accounts with fictional handles; the 40 cached YouTube creators arrive with the M4 adapter. Nothing in the database came from a real person.
