# Scope

What is Live, what is Seeded, and what was cut. Updated at the end of every milestone.

Live means a real external API or real database logic in the production build. Seeded means synthetic data. If a milestone cannot meet its definition of done, this file says so and the page shows the same message.

## Data

All customer, kit, panel, ticket and attribution rows are synthetic, generated by `lib/synthetic` from a fixed seed. Creators are 30 seeded Instagram and TikTok accounts with fictional handles plus 40 real YouTube channels captured by `pnpm discover` (public professional-account data only: channel title, description, subscriber count, recent video titles and their view, like and comment counts) and stored as a Seeded snapshot until the running build re-fetches them. Cross-linked Instagram and TikTok handles named in those public descriptions become Seeded rows with no metrics. No customer, kit, panel or ticket row came from a real person.

## Model provider

The copilot and the ticket summariser run on whichever vendor `MODEL_PROVIDER` names. The demo runs on Gemini (`gemini-2.5-flash`, free tier) because the Anthropic account had no credits at M3; the Anthropic path is the CLAUDE.md default and stays wired. The 15 evals in `evals/copilot.json` pass 15/15 on Gemini (two consecutive runs). They have not been run on Anthropic yet; the loop, guard, tools and both provider adapters are covered by unit tests with fake clients.
