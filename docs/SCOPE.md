# Scope

## Data

All customer, kit, panel, ticket and attribution rows are synthetic, generated by `lib/synthetic` from a fixed seed. Creators are 30 seeded Instagram and TikTok accounts with fictional handles plus 40 real YouTube channels captured by `pnpm discover`, each above a 1,000-subscriber floor so the set is partnership prospects rather than private individuals (public channel data only: title, description, subscriber count, recent video titles and their view, like and comment counts, with every email address and phone number redacted on the way in) and stored as a Seeded snapshot until the running build re-fetches them. Cross-linked Instagram and TikTok handles named in those public descriptions become Seeded rows with no metrics. No customer, kit, panel or ticket row came from a real person.

## Model provider

The copilot and the ticket summariser run on whichever vendor `MODEL_PROVIDER` names. The demo runs on Gemini (`gemini-2.5-flash`, free tier) because the Anthropic account had no credits at M3; the Anthropic path is the CLAUDE.md default and stays wired. The 15 evals in `evals/copilot.json` pass 15/15 on Gemini (two consecutive runs). They have not been run on Anthropic yet; the loop, guard, tools and both provider adapters are covered by unit tests with fake clients.

## Privacy guard

A query may group by and filter on at most three dimensions in total. Suppressing a cell hides its count, not the fact that the cell exists, so a deep enough grouping is a re-identification attack even when every cell is suppressed: seven dimensions over 209 consenting customers returned 209 suppressed cells, each a unique quasi-identifier tuple for one person, in database order. The guard now refuses those queries, counts filters toward the limit, and sorts cells by dimension value so the output order carries no information. Found by the M8 review; the regression tests are in `tests/intelligence/`.


The demo dataset runs with a minimum cohort of 10 (500 synthetic customers, 209 of them consenting to research). The production default in code is 50. The setting is editable on `/intelligence` and applies to every aggregate, export and the brand control cohort.
